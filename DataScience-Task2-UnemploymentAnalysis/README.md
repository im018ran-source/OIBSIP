# Task 2: Unemployment Analysis with Python

## Objective
Perform exploratory data analysis on unemployment data to uncover regional and temporal trends, focusing on the impact of the COVID-19 pandemic.

## Tech Stack
- Python, pandas, numpy
- matplotlib, seaborn
- Jupyter Notebook

## Key Findings
