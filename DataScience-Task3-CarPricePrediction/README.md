# Task 3: Car Price Prediction with Machine Learning

## Objective
Build a machine learning regression model to predict the selling price of used cars based on attributes like present price, driven kilometers, fuel type, transmission, and car age.

## Tech Stack
- Python, pandas, numpy
- scikit-learn
- matplotlib, seaborn

## Workflow & Features
- **Data Cleaning & Engineering:** Created a new `Car_Age` feature from the manufacturing year and extracted vehicle brands.
- **EDA:** Visualized price distributions, fuel-type price variations, and depreciation over time.
- **Modeling:** Trained and evaluated **Linear Regression** and **Random Forest Regressor**.
- **Evaluation Metrics:** Compared models using MAE, RMSE, and R^2 score.
